# MNIST Classification

This project follows **Chapter 3 — Classification** of _Hands-On Machine Learning_.

The goal is to understand the main concepts behind classification by working with the **MNIST handwritten digits dataset** using Scikit-Learn.

## Topics Covered

- Binary Classification
- Dummy Classifier
- Cross-Validation
- Confusion Matrix
- Precision, Recall, and F1 Score
- Decision Thresholds
- Precision-Recall Trade-off
- ROC Curve and ROC AUC
- Random Forest
- Error Analysis
- Data Augmentation
- Multiclass Classification
- Multilabel Classification
- Classifier Chains
- Multioutput Classification

## Main Models

- `DummyClassifier`
- `SGDClassifier`
- `RandomForestClassifier`
- `KNeighborsClassifier`
- `SVC`
- `ClassifierChain`

## Dataset

The project uses the **MNIST** dataset, consisting of grayscale images of handwritten digits.

Each image is **28×28 pixels**, represented as **784 features** after flattening.

## Purpose

This is primarily an **educational project** focused on understanding classification concepts, evaluating models, analyzing errors, and exploring different types of classification tasks.
